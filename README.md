# 🏔️ Peak Pulse

**Peak Pulse** is a mountain and fitness tracking website designed to help users explore mountains, track their running activities, and monitor their fitness journey.

🌐 **Live Website:** https://peakpulse.ai.studio/

---

## ✨ Features

- 🏔️ **Mountain Exploration** — Discover mountain destinations and outdoor adventures.
- 🏃 **Running Tracker** — Track running activities and monitor progress.
- 📊 **Activity Dashboard** — View fitness activities and performance statistics.
- 🎯 **Fitness Goals** — Stay motivated and work toward personal goals.
- 📱 **Responsive Design** — Enjoy a seamless experience across desktop and mobile devices.
- 🎨 **Modern UI** — Clean, intuitive, and user-friendly interface.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Navigate to the project directory

```bash
cd YOUR-REPOSITORY
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit the local URL provided in your terminal, usually:

```text
http://localhost:5173
```
